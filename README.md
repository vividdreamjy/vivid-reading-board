# 독서 인증 보드

독서 인증 사진을 날짜별로 모아 **누가 인증했고 누가 빠졌는지**, 그리고 **개인별로 얼마나 쌓았는지**를 한눈에 보여주는 30일 챌린지 보드입니다.

## 화면

| 탭 | 내용 |
|---|---|
| 현황 | 오늘 인증 완료 / 미인증 멤버, 전체 달성률 |
| 날짜별 표 | 날짜 × 멤버 격자. 날짜를 누르면 그날 인증자·미인증자 상세 |
| 누적 랭킹 | 누적 인증 횟수, 최장 연속, 현재 연속, 달성률 |
| 사진 | 인증 사진 전체 갤러리 (최신순) |
| 설정 | 챌린지 이름·시작일·기간, 멤버 명단 관리, 백업/복원 |

## 저장 방식

- 챌린지·멤버·인증 기록 → 브라우저 `localStorage`
- 인증 사진 → 브라우저 `IndexedDB` (긴 변 1200px, JPEG 82%로 축소 후 저장)

**기기·브라우저마다 데이터가 따로 저장됩니다.** 여러 사람이 각자 폰에서 인증하고 하나의 보드를 공유하려면 Supabase 같은 백엔드 연결이 필요합니다. 그 전까지는 설정 탭의 **백업 / 복원(JSON)** 으로 기기 간 이동이 가능합니다.

## 실행

정적 파일 하나입니다. 빌드 과정이 없습니다.

```bash
npx serve .
# 또는 index.html을 브라우저로 바로 열기
```

## 배포

Vercel에 이 저장소를 연결하면 됩니다. 프레임워크 `Other`, 빌드 명령 없음, 출력 디렉터리 `.`

## 파일

- `index.html` — 앱 전체 (HTML + CSS + JS 단일 파일)
- `app-body.html` — `<body>` 내용만 담은 원본
- `build.py` — `app-body.html`을 감싸 `index.html`을 생성

## 다음 단계 (Supabase)
